1. Scope

This Privacy Policy applies to sammyjoze.com and all software, Chrome extensions, web apps, desktop apps, and related services published by Sammy Joze (collectively, the “Services”).

This is an umbrella policy covering all extensions and apps we publish, including:

  • Chrome extensions (including Select Lens and other extensions)
  • Web apps
  • Desktop apps
  • Product websites that reference or link to this policy

By using any Service, you acknowledge this policy. Product-specific details for Select Lens are also published at sammyjoze.com/privacy/select-lens.

We do not sell your personal information. We also do not use your data to determine creditworthiness, eligibility for a loan, or for lending purposes.

2. User data collection

What we collect depends on which product you use. Across our Services, we may process:

  • Account information — email address, display name, authentication credentials, and profile settings when you create an account for an account-based Service.
  • User content — data you choose to store or submit in an app (for example, vault entries or app records).
  • API keys and credentials you provide — third-party keys you enter for BYOK features (for Select Lens, your OpenAI API key stored locally; see Select Lens).
  • Website content you actively use — page text or selections an extension reads only when you invoke a feature.
  • Service logs — for account-based Services and websites: timestamps, IP addresses, device or browser type, error reports, and performance metrics needed to run and secure the Service.
  • Support messages — information you send when contacting us, including email content and attachments.

For Select Lens specifically: we do not collect your OpenAI API key or highlighted text on our servers. See Select Lens and Select Lens privacy.

3. User data handling

We handle information we process only to:

  • Provide the Services — authenticate accounts, sync encrypted data where applicable, run apps, and deliver features you request.
  • Operate and improve — maintain uptime, fix bugs, understand usage patterns in aggregate, and develop new features.
  • Security and abuse prevention — detect fraud, protect accounts, and enforce our Terms of Service.
  • Support — respond to your questions and troubleshoot issues you report.
  • Legal compliance — meet applicable legal obligations and respond to lawful requests.

For Select Lens: handling of your API key and highlighted text occurs on your device and between your browser and OpenAI. Sammy Joze does not handle that data on our servers.

We do not sell personal information. We do not use your data for creditworthiness or lending decisions. We do not use vault contents or BYOK extension data for advertising profiles.

4. User data storage

Storage depends on product type:

  • Select Lens / BYOK extensions — API keys are stored in browser local storage (for Select Lens: chrome.storage.local on your device only). Highlighted text and AI results are not stored on Sammy Joze servers.
  • Account-based apps — account data and encrypted payloads may be stored on our infrastructure (or providers we use). Sensitive vault-style data is encrypted client-side before sync where the product describes that model.
  • Utility extensions — many features use local browser storage only, as described in each Chrome Web Store listing.
  • Support email — messages you send to us may be retained as needed to respond and for legitimate business records.

We retain account and service data for as long as your account is active or as needed to provide the Service. After account deletion, we delete or anonymize data within a reasonable period, except where retention is required by law or for security (for example, backup cycles or dispute resolution).

We use industry-standard measures including encryption in transit (TLS) and access controls. No method of transmission or storage is 100% secure.

5. User data sharing

We may share information only in these circumstances:

  • Infrastructure providers — hosting, databases, email delivery, and similar vendors that help us operate account-based Services and websites, under contractual obligations to protect data.
  • Third parties you connect — for Select Lens, selected text goes to OpenAI when you run an action, using your API key. Sammy Joze does not receive that key or text. Other products may connect to providers you explicitly enable.
  • Legal requirements — when required by law, regulation, legal process, or to protect the rights, safety, and security of users and Sammy Joze.
  • Business transfers — in connection with a merger, acquisition, or sale of assets, with notice where required by law.

We do not sell personal information to data brokers or advertising networks. We do not share Select Lens API keys or highlights with Sammy Joze servers or with third parties other than OpenAI as described above when you trigger a feature.

6. Select Lens (Chrome extension)

Select Lens is a Chrome extension that helps you define, summarize, simplify, or break down highlighted text using your own OpenAI API key (bring-your-own-key / BYOK). Select Lens does not require a Sammy Joze account. Full Select Lens-only policy: /privacy/select-lens.

User data collection

Select Lens collects or processes only:

  • Your OpenAI API key, which you enter in the extension settings.
  • Highlighted page text, only when you actively run an action (Define, Steps, Summary, or Simplify).
  • Optional page title and URL when included with an action you trigger.

Select Lens does not collect browsing history, credentials other than the key you provide, or unrelated page content in the background.

User data handling

When you run an action, your browser sends the highlighted text to OpenAI over HTTPS, authenticated with your OpenAI API key. Requests go browser → OpenAI. Sammy Joze does not proxy, inspect, or relay these requests.

User data storage

Your OpenAI API key is stored only in chrome.storage.local on your device. Highlighted text and AI results are not stored on Sammy Joze servers. We do not receive or retain your API key, highlights, or AI responses.

User data sharing

Selected text is shared with OpenAI only when you run an action, using your key and subject to OpenAI’s terms and privacy policy. Sammy Joze does not receive your API key or highlighted text. You are responsible for your OpenAI account, usage limits, and fees.

8. Chrome Web Store Limited Use

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

9. Your choices

Depending on the product, you can:

  • Export data — use in-product export tools where available.
  • Delete your account — contact us or use account deletion options in the relevant app.
  • Revoke API keys — remove or rotate keys in extension settings (for Select Lens: clear the key from settings) and at your API provider (for example, OpenAI).
  • Uninstall extensions — remove Chrome extensions from your browser; local data such as chrome.storage.local is cleared according to Chrome’s rules.
  • Manage browser permissions — review and revoke site access or permissions granted to any extension in Chrome settings.
  • Opt out of non-essential communications — unsubscribe from marketing emails where offered; transactional and security messages may still be sent.

10. Children's privacy

Our Services are not directed to children under 13 (or the minimum age required in your jurisdiction). We do not knowingly collect personal information from children. If you believe a child has provided us personal information, contact us and we will take steps to delete it.

When we make material changes, we will update the “Last updated” date at the top of this page and, where appropriate, notify you through the Service or by email. Continued use after changes take effect constitutes acceptance of the updated policy.
