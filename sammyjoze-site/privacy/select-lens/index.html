Overview

Select Lens is a Chrome extension that helps you define, summarize, simplify, or break into steps text you highlight on a webpage. It uses your own OpenAI API key (bring-your-own-key / BYOK). No Sammy Joze account is required.

We do not sell your personal information. We do not use Select Lens data to determine creditworthiness or for lending. Sammy Joze does not receive your OpenAI API key or highlighted text on our servers.

User data collection

Select Lens collects or processes the following user data:

  • OpenAI API key — entered by you in the extension popup/settings so the extension can call OpenAI on your behalf.
  • Highlighted webpage text — only when you actively choose an action (Define, Steps, Summary, or Simplify).
  • Optional page context — page title and page URL may be included with the request you trigger, to improve the AI response.

Select Lens does not collect browsing history in the background, passwords, payment details, or unrelated page content when you are not using a feature.

User data handling

How Select Lens handles user data:

  • When you run an action, your browser sends the highlighted text (and optional page title/URL) to OpenAI over HTTPS, authenticated with your OpenAI API key.
  • The request path is browser → OpenAI. Sammy Joze does not proxy, inspect, or relay these requests.
  • Data is used only to generate the AI result for the single purpose of Select Lens (define, steps, summary, or simplify).
  • We do not use Select Lens data for advertising, profiling unrelated to the feature, credit decisions, or lending.

User data storage

  • OpenAI API key — stored only in chrome.storage.local on your device. It is not uploaded to Sammy Joze servers.
  • Highlighted text and AI results — shown in your browser during the session; not stored on Sammy Joze servers.
  • Retention on device — your key remains until you remove it in Select Lens settings or uninstall the extension (Chrome then clears extension storage per Chrome rules).
  • Transmissions to OpenAI use modern cryptography (HTTPS/TLS).

User data sharing

Select Lens shares user data only as follows:

  • OpenAI — selected text (and optional page title/URL) is shared with OpenAI when you run an action, using your API key and subject to OpenAI’s terms and privacy policy.
  • Sammy Joze — does not receive your API key, highlighted text, or AI responses from Select Lens AI actions.
  • Legal requirements — we may disclose information if required by law for other Sammy Joze services; Select Lens BYOK traffic does not pass through our servers.

We do not sell personal information to data brokers or advertising networks. We do not transfer Select Lens user data for purposes unrelated to the extension’s single purpose, except as allowed by the Chrome Web Store User Data Policy.

Chrome Web Store Limited Use

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Your choices

  • Clear or replace your OpenAI API key in Select Lens settings at any time.
  • Rotate or revoke the key in your OpenAI account.
  • Uninstall Select Lens to remove local extension storage per Chrome rules.
  • Manage site/extension permissions in Chrome settings.
